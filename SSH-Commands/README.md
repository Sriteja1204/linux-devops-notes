# SSH Commands in Linux

This repository contains documentation for commonly used SSH (Secure Shell) commands in Linux.

## Commands Included

- `ssh` → Connect to remote systems securely
- `ssh-keygen` → Generate SSH key pairs
- `ssh with private key` → Connect using SSH private key authentication

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand SSH fundamentals
- Connect to remote Linux servers securely
- Generate and manage SSH key pairs
- Authenticate using private keys
- Apply SSH commands in real-world server administration
