# Redirection and Pipes in Linux

This repository contains documentation for commonly used Linux redirection operators and pipe commands.

## Topics Included

- `|` → Pipe operator
- `>` → Overwrite operator
- `>>` → Append operator

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand Linux input and output redirection
- Use pipes to combine multiple commands
- Redirect command outputs into files
- Append data safely without overwriting files
- Apply redirection and piping in real-world Linux environments
