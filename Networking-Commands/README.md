# Networking Commands in Linux

This repository contains documentation for commonly used Linux networking commands.

## Commands Included

- `ping` → Test network connectivity
- `curl` → Transfer data from or to a server
- `wget` → Download files from the internet

---

## Learning Objectives

By the end of this module, you will be able to:

- Test network connectivity using Linux commands
- Transfer and download files from servers
- Diagnose basic networking issues
- Work with web resources from the terminal
- Use networking commands in real-world Linux environments
