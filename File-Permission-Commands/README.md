# File Permission Commands in Linux

This repository contains documentation for commonly used Linux file permission and ownership commands.

## Commands Included

- `chmod` → Change file permissions
- `chown` → Change file ownership

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand Linux file permission concepts
- Modify file and directory permissions using `chmod`
- Change file ownership using `chown`
- Apply permission management in real-world Linux environments
- Secure files and directories effectively
- Use permission commands safely in system administration
