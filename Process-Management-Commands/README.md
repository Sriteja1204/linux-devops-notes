# Process Management Commands in Linux

This repository contains documentation for commonly used Linux process management commands.

## Commands Included

- `ps` → Display running processes
- `top` → Monitor system processes in real time
- `kill` → Terminate processes
- `systemctl` → Manage system services

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand Linux process management concepts
- Monitor running processes and system resources
- Terminate unwanted or unresponsive processes
- Manage Linux services using `systemctl`
- Apply process management in real-world Linux environments
