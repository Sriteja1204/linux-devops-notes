# System Information Commands in Linux

This repository contains documentation for commonly used Linux system information commands.

## Commands Included

- `uname` → Display system and kernel information
- `df` → Show disk space usage
- `free` → Display memory usage information

---

## Learning Objectives

By the end of this module, you will be able to:

- Retrieve Linux system information
- Monitor disk storage usage
- Analyze system memory usage
- Understand kernel and architecture details
- Apply system monitoring commands in real-world Linux environments
