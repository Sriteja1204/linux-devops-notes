# Important Linux Symbols

This repository contains documentation for commonly used Linux symbols and operators.

## Topics Included

- `~` → Home directory
- `/` → Root directory separator
- `.` → Current directory
- `..` → Parent directory
- `*` → Wildcard operator
- `|` → Pipe operator
- `>` → Output overwrite operator
- `>>` → Output append operator
- `&` → Run process in background

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand commonly used Linux symbols
- Navigate directories efficiently
- Use wildcard and redirection operators
- Combine commands using pipes
- Apply Linux symbols in real-world terminal operations
