## Introduction

The `whoami` command displays the username of the currently logged-in user.

---

## Learning Objective

By the end of this document, you will be able to:

- Identify the current active user
- Verify user identity in Linux
- Use `whoami` in scripts and administration tasks
- Understand user session information

---

## Purpose

- Display current username
- Verify user permissions
- Check active account details

---

## Syntax

```bash
whoami
```

---

## Examples

### Display current user

```bash
whoami
```

Output:

```bash
student
```

---

## Option Explanation

| Option | Description |
|--------|-------------|
| `--help` | Display help information |
| `--version` | Show command version |

---

## Real-Time Usage

- Verifying current user before running commands
- Checking account identity on servers
- Using in shell scripts

Example:

```bash
whoami
```

---

## Important Notes

- Displays only the active username
- Helpful during multi-user sessions
- Often used with permission management
