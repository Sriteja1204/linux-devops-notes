# User Management Commands in Linux

This repository contains documentation for commonly used Linux user management commands.

## Commands Included

- `whoami` → Display current logged-in user
- `sudo` → Execute commands with administrative privileges
- `su` → Switch user accounts

---

## Learning Objectives

By the end of this module, you will be able to:

- Identify the currently logged-in user
- Execute administrative commands securely
- Switch between user accounts
- Understand privilege management in Linux
- Apply user management commands in real-world environments
