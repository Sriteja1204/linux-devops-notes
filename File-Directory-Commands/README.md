# File and Directory Commands in Linux

This repository contains documentation for commonly used Linux file and directory management commands.

## Commands Included

- `mkdir` → Create directories
- `touch` → Create empty files
- `cp` → Copy files and directories
- `mv` → Move or rename files
- `rm` → Remove files and directories
- `find` → Search files and directories

Each command documentation includes:

- Introduction
- Purpose
- Syntax
- Examples
- Option Explanation
- Real-Time Usage
- Important Notes

## Learning Objective

By the end of this document, you will be able to:

- Understand the purpose of the command
- Use the command with proper syntax
- Work with commonly used options
- Apply the command in real-time Linux environments
